Easy Farm Hub

A digital hub for farmers that provides organic farming technologies, government schemes, and product management with bilingual (English/Gujarati) support.

Project Highlights

Key functionality and technologies used in this project — clean, secure and production-ready.

Functionality

  • User and admin login system
  • User registration with multi-language support (English/Gujarati)
  • Admin can add and manage products
  • Admin can publish organic farming technologies
  • Admin can share new government schemes
Login Farming Multi-Language Schemes

Technology

  • Frontend: HTML, CSS, Bootstrap, JavaScript
  • Backend: PHP (server-side logic)
  • Database: MySQL
  • Language Support: English ↔ Gujarati toggle
  • Hosting & Infra: Localhost / Web server (e.g., XAMPP, Apache)
